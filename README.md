## 📌 Project Overview

FleetFocus is a web-based Fleet Telematics Management System developed to simplify fleet operations for organizations.

The application provides secure authentication and role-based access while allowing administrators to manage:

- 🚗 Vehicles
- 👨‍✈️ Drivers
- 🛣️ Trips
- 🔧 Maintenance Logs
- 👥 Users

The system also includes a dashboard that provides an overview of fleet statistics and operational status.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/GNANAVIGNESH2006/FleetFocus.git
```

---

## Backend

```bash
cd backend
```

Run

```bash
mvn spring-boot:run
```

Backend runs on

```
http://localhost:8080
```

---

## Frontend

Open

```
frontend/index.html
```

using Live Server.
